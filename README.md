Hello everybody! Here is some information you should know about Chaos Snake!

**So, what is Chaos Snake?**
- Chaos Snake is my version of the classic game "Snake", known and loved by many people. The reason why my version is called **Chaos** Snake is that I have added a couple of new features to make it feel more chaotic! Here is a list of them:

**1) Moving Apples**
- The Move Apples feature makes the apples run from you, and it's random for every apple! They can run in 8 directions (straight and diagonally), and when they collide with either a wall or you (the player), the apples turn around and start running/moving away in the opposite direction. This feature can be a little buggy though, but at least there's more chaos :)

**2) Spawn Mines**
- Mines are a pretty big part of the game, however some people might not like playing with them. So there's a switch for it! It is strongly recommended you turn this on, but only at your own risk.

**3) Move Mines**
- This feature is exactly what it sounds like. When turned on, mines will move after every 10th eaten apple. Works only with **Spawn Mines** turned on.

**4) Spawn New Mine After Every Apple**
- This is where the real chaos begins! When turned on, mines spawn after each apple you eat. So, the more apples you eat, the more mines there will be! Works only with **Spawn Mines** turned on.

**5) Move Mines After Every Apple**
- With this setting, the mines move after each apple you eat, making them very unpredictable and fun to avoid. Works only with **Spawn Mines** turned on.

Now there is a 6th switch, and that is the **CHAOS** switch. When turned on, every single one of the previous settings turns on, enabling the TRUE chaos mode. And the menu lets you know that ;)

Hope you'll have fun playing the game!
